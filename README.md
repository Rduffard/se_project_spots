# Project 3: Spots

### Overview

- Intro
- Links

**Intro**
This is my third project from Tripleten. It is a simple social media platform that allows the user to update profile and avatar image as well as add posts with an image and a description.

**Features**

- This project features responsive design, hidden text overflow, and use of grid display.
- New updates include funtionality using Javascript such as opening and closing modals, and handling form data.
- With Api functionality, the site now saves the user's data with server communication.
- Users are now able to update their Avatar as well.
- The site has been bundled using Webpack.
- Lastly, buttons now give loading feedback while the server makes and recieves requests.
